Live features

Same definitions as analyze.py: hold = keyup − keydown per key; flight = keydown → next keydown; speed = keydowns per second; errors = Backspace/Delete share of keydowns.

Session

Samples persist in this browser's localStorage until you clear them. Export JSON is the file analyze.py and the pipeline read.

Collection checklist

• 5+ calm samples per person, 5+ stress samples per person.
• Stress = set a short timer (15–25 s) and have someone bark at you.
• Use the same physical keyboard for a person's whole set.
• Don't paste, don't switch windows mid-sample (blurs are counted).
• Export after every session. A refresh keeps data; a cleared cache doesn't.
